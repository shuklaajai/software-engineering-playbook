# 📈 Statistics

Statistical methods, probability theory, and hypothesis testing.

## 📚 Topics Covered

- **Descriptive Statistics** - Mean, median, std dev, skewness
- **Probability Theory** - Distributions, Bayes theorem, CLT
- **Inferential Statistics** - Hypothesis testing, confidence intervals
- **Regression Analysis** - Linear, logistic, polynomial regression
- **ANOVA & Tests** - T-test, chi-square, ANOVA, Kruskal-Wallis
- **Bayesian Methods** - Bayesian inference, conjugate priors
- **Time Series** - Stationarity, ARIMA, seasonal decomposition
- **Experimental Design** - A/B testing, sample sizing
