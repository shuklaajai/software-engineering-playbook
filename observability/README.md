# 👁️ Observability

Monitoring, logging, tracing, and metrics collection.

## 📚 Topics Covered

- **Metrics** - Prometheus, TimescaleDB, InfluxDB
- **Logging** - ELK stack, Splunk, CloudWatch Logs
- **Tracing** - Jaeger, Zipkin, X-Ray
- **Dashboarding** - Grafana, Kibana, CloudWatch
- **Alerting** - Alert rules, notification channels
- **APM** - Application Performance Monitoring
- **Log Analysis** - Pattern detection, anomaly detection
- **Health Checks** - Liveness, readiness, startup probes
