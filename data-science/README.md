# 📊 Data Science

Data analysis, visualization, and insights extraction.

## 📚 Topics Covered

- **Data Exploration** - EDA, descriptive statistics
- **Data Cleaning** - Missing values, outliers, normalization
- **Analysis Techniques** - Correlation, regression, clustering
- **Visualization** - Matplotlib, Seaborn, Plotly, Dash
- **Business Intelligence** - Dashboards, reporting
- **Big Data** - Spark, Hadoop basics
- **Tools** - Pandas, NumPy, SQL
- **Business Acumen** - KPIs, metrics, storytelling
