# ☁️ Cloud Infrastructure

AWS services, architecture patterns, and best practices.

## 📚 Topics Covered

- **Compute** - EC2, Lambda, ECS, Fargate, App Runner
- **Storage** - S3, EBS, EFS, Glacier
- **Databases** - RDS, DynamoDB, ElastiCache, Neptune
- **Networking** - VPC, ALB/NLB, CloudFront, Route53
- **Security** - IAM, Secrets Manager, KMS, GuardDuty
- **Monitoring** - CloudWatch, X-Ray, EventBridge
- **CI/CD** - CodePipeline, CodeBuild, CodeDeploy
- **Container Services** - ECS, ECR, EKS
