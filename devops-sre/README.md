# ⚙️ DevOps & SRE

CI/CD pipelines, automation, reliability practices, and operational excellence.

## 📚 Topics Covered

- **CI/CD Pipelines** - GitHub Actions, GitLab CI, Jenkins
- **Version Control** - Git workflows, branching strategies
- **Automation** - Infrastructure automation, deployment scripts
- **Monitoring & Alerting** - Prometheus, Grafana, PagerDuty
- **Incident Management** - On-call rotation, runbooks, postmortems
- **Reliability** - SLOs, error budgets, chaos engineering
- **Deployment Strategies** - Blue-green, canary, rolling
- **Infrastructure Automation** - Scripts, tools, orchestration
