# 🏛️ System Architecture

Architecture patterns, design principles, and system design.

## 📚 Topics Covered

- **Design Patterns** - MVC, MVVM, Repository, Factory, Singleton
- **Architectural Patterns** - Microservices, Monolithic, Serverless
- **Scalability** - Horizontal/vertical scaling, load balancing
- **High Availability** - Redundancy, failover, disaster recovery
- **API Design** - REST, GraphQL, gRPC
- **Database Design** - ACID, CAP theorem, sharding
- **Security Architecture** - Defense in depth, zero trust
- **System Design Interview** - Case studies and walkthroughs
